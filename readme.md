# DCS-Scripts

Scripts Lua, documentación y prompts para misiones de DCS World.

## Estructura

```
DCS-Scripts/
├── docs/       — documentación, dashboards y referencias
├── scripts/    — scripts Lua para DCS/MOOSE
└── prompts/    — prompts para Claude Code y GitHub Copilot
```

## Requisitos

- DCS World
- MOOSE Framework (opcional, según script)
